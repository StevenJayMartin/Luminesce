# RAG Tools

RAG tools allow Luminesce to ingest and query documents.

---

## rag_ingest

```
rag_ingest(url="https://example.com")
```

Downloads and indexes a webpage.

---

## rag_query

```
rag_query(query="What is the topic?")
```

Searches ingested documents.
