⭐ RAG Server — Impatient Install & Setup Guide (Strict + Concise)
0. Clone down the repo
git clone https://github.com/StevenJayMartin/Luminesce.git

1. Install dependencies (on the backend box)
bash
pip install fastapi uvicorn faiss-cpu numpy requests ollama beautifulsoup4 lxml
2. Pull the embedding model (required)
bash
ollama pull nomic-embed-text
Without this, RAG will throw:

Code
model "nomic-embed-text" not found
3. Ensure RAG directory exists
Code
lumin/rag_server/
    server.py
    embeddings.py
    vector_store.py
    ingest.py
    retrieval.py
    __init__.py
4. Start the RAG server
bash
uvicorn lumin.rag_server.server:app --host 0.0.0.0 --port 8001
RAG is now live at:

Code
http://<backend-ip>:8001/rag
5. Enable RAG in Luminesce UI config.json
json
"rag": {
  "enabled": true,
  "url": "http://192.168.1.205:8001/rag"
}
Luminesce will:

use RAG if reachable

fall back automatically if not

6. Test RAG
bash
curl -X POST http://192.168.1.205:8001/rag \
     -H "Content-Type: application/json" \
     -d '{"query": "hello", "session": "test"}'
If JSON returns → RAG is working.

7. Ingest a webpage (Internet RAG)
bash
python3 - << 'EOF'
from lumin.rag_server.ingest import ingest_url
ingest_url("https://en.wikipedia.org/wiki/FAISS")
EOF
8. Optional: systemd auto‑start
Create:

Code
/etc/systemd/system/lumin-rag.service
Contents:

Code
[Unit]
Description=Luminesce RAG Server
After=network.target

[Service]
Type=simple
User=YOUR_USERNAME
WorkingDirectory=/path/to/Luminesce
ExecStart=/usr/bin/python3 -m uvicorn lumin.rag_server.server:app --host 0.0.0.0 --port 8001
Restart=always

[Install]
WantedBy=multi-user.target
Enable:

bash
sudo systemctl daemon-reload
sudo systemctl enable lumin-rag.service
sudo systemctl start lumin-rag.service
Check:

bash
sudo systemctl status lumin-rag.service
⭐ Done
This is the minimal, strict, impatient‑friendly RAG setup doc:

install deps

pull embedding model

run server

enable in config

ingest

optional systemd
