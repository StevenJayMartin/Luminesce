⭐ Luminesce RAG Backend — Quick Setup Guide
1. Install dependencies (LLM backend box)
bash
pip install fastapi uvicorn faiss-cpu numpy requests ollama beautifulsoup4 lxml
This gives you:

FastAPI + Uvicorn → the RAG server

FAISS → vector search

numpy → embeddings

requests → web fetch

BeautifulSoup + lxml → internet RAG

ollama → embedding model

2. Place the RAG server code
On your LLM backend machine, ensure this directory exists:

Code
lumin/rag_server/
    server.py
    embeddings.py
    vector_store.py
    ingest.py
    retrieval.py
    __init__.py
(You already have the scaffold.)

3. Start the RAG server
From your project root:

bash
uvicorn lumin.rag_server.server:app --host 0.0.0.0 --port 8001
Your RAG endpoint is now live at:

Code
http://<backend-ip>:8001/rag
4. Enable RAG in Luminesce UI config.json
On your UI machine:

json
"rag": {
  "enabled": true,
  "url": "http://192.168.1.205:8001/rag"
}
Luminesce will automatically:

use RAG if reachable

fall back to normal chat if not

No restart required.

5. Test the RAG endpoint
bash
curl -X POST http://192.168.1.205:8001/rag \
     -H "Content-Type: application/json" \
     -d '{"query": "hello", "session": "test"}'
If you get JSON → RAG is working.

6. Ingest a webpage (Internet RAG)
bash
python3 - << 'EOF'
from lumin.rag_server.ingest import ingest_url
ingest_url("https://en.wikipedia.org/wiki/FAISS")
EOF
Now your RAG server knows that page.

7. Optional: systemd service (auto‑start on boot)
Create:

Code
/etc/systemd/system/lumin-rag.service
Contents:

Code
[Unit]
Description=Luminesce RAG Server
After=network.target

[Service]
Type=simple
User=YOUR_USERNAME
WorkingDirectory=/path/to/Luminesce
ExecStart=/usr/bin/python3 -m uvicorn lumin.rag_server.server:app --host 0.0.0.0 --port 8001
Restart=always

[Install]
WantedBy=multi-user.target
Enable it:

bash
sudo systemctl daemon-reload
sudo systemctl enable lumin-rag.service
sudo systemctl start lumin-rag.service
Check status:

bash
sudo systemctl status lumin-rag.service
⭐ That’s it — RAG is now running on your big backend box
You now have:

RAG server running

Internet ingestion working

Luminesce UI automatically using RAG

Full fallback if RAG is offline

Optional systemd auto‑start
